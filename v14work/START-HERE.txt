DOSEIQ PROFESSIONAL V1
=======================

Aapko coding karne ki zaroorat nahi. Is folder ko VS Code mein open karein.

WINDOWS PAR RUN KARNE KA TARIKA
--------------------------------
1. VS Code mein is folder ko open karein.
2. Terminal > New Terminal kholein.
3. Ye commands ek ek karke chalayein:

   npm install
   npm run dev

4. Terminal mein Vite ka Local address aaye ga, aam tor par:

   http://localhost:5173/

5. Us address ko Chrome mein open karein.

IMPORTANT
---------
- Root folder mein hi terminal kholna hai, client folder ke andar nahi.
- Agar pehle npm install mein warning aaye to warning aur error ko alag samjhein.
- Agar npm run dev par error aaye to terminal ki screenshot bhej dein.
